Coût des seules frontières
—
F1(Type) − F1(Strict) : crédit rendu quand on tolère le glissement de frontière (type correct)
Coût des seuls types
—
F1(Exact) − F1(Strict) : crédit rendu quand on ignore le type (frontière exacte)

Chaque prédiction est appariée à une entité de référence puis classée en COR / INC / PAR / MIS / SPU (schéma MUC repris par SemEval'13, tâche 9.1). Une frontière exacte et le bon type donnent COR ; une frontière exacte au mauvais type est INC en Strict mais COR en Exact ; un simple chevauchement (frontière glissée) est INC en Strict/Exact, PAR en Partial et COR en Type si le type concorde. On pose POS = COR+INC+PAR+MIS (réf.) et ACT = COR+INC+PAR+SPU (préd.). Strict et Exact comptent P = COR/ACT, R = COR/POS ; Partial et Type accordent le demi-crédit P = (COR+0,5·PAR)/ACT, R = (COR+0,5·PAR)/POS, puis F1 = 2PR/(P+R). Le mode Strict reproduit le F1 tout-ou-rien de CoNLL-2003 (conlleval) : frontière + type exigés, aucun demi-crédit.
