Sélectivité dépendante de l'entrée (S6) : Δt filtre, le LTI subit

Tâche jouet de copie sélective : une séquence mêle quelques tokens contenu à beaucoup de tokens bruit. Un état scalaire h (A = −1, fixe, < 0 pour la stabilité) doit mémoriser le dernier contenu et ignorer le bruit. On compare un SSM LTI (Δ, B, C fixes, identiques pour tous les tokens) à un SSM sélectif (S6) où Δt, Bt, Ct dépendent du token. Cliquez un token pour basculer contenu ↔ bruit (= changer sa pertinence), réglez la sélectivité et le Δ du LTI, et observez qui suit la cible.

Pourquoi le LTI échoue — et ce que Δt fait exactement

La porte Δt. Avec A = −1, Āt = exp(Δt·A) = exp(−Δt) et B̄t = (1−Āt)·Bt. Δt joue le rôle d'une porte à la GRU :

  • Token pertinent → Δt grand : Āt ≈ 0, B̄t ≈ 1. On efface l'état accumulé (le bruit antérieur) et on écrit la charge utile : ht ≈ xt. C'est le sens de « Δ grand → oubli du bruit ».
  • Token bruit → Δt petit : Āt ≈ 1, B̄t ≈ 0. On préserve la mémoire (le contenu déjà stocké) et on ignore le token courant : ht ≈ ht−1. C'est « Δ petit → rétention du contenu ».

Le dilemme LTI. Le SSM LTI applique un seul Δ à tous les tokens. Δ grand → il capture le contenu mais réécrit aussi l'état à chaque bruit (mémoire détruite) ; Δ petit → il ignore le bruit mais n'écrit jamais vraiment le contenu (mémoire vide). Le score meilleur Δ LTI balaie toutes les valeurs : aucune ne rivalise avec le sélectif, parce que le bon Δ dépend du token — exactement ce que le LTI ne peut pas exprimer.

Le noyau devient temps-variant : plus de convolution fixe

En LTI, A, B, C sont constants, donc le noyau K[k] = C·Āk·B̄ ne dépend que du décalage k : un seul noyau, précalculable, appliqué par convolution (FFT) sur toute la séquence. Dès que Δt, Bt, Ct dépendent de l'entrée, le noyau Kt[k] = Ct·(Āt···Āt−k+1)·B̄t−k change à chaque position t : il n'existe plus de noyau fixe. La vue Noyau Kt trace, pour le token sélectionné comme position courante t, l'influence résiduelle de chaque token passé sur ht. En sélectif, un contenu (Ā ≈ 0) coupe net l'influence de tout ce qui le précède (reset) : seuls le dernier contenu et le bruit qui l'a suivi pèsent encore. En LTI, la même décroissance géométrique s'applique partout, sans distinguer contenu et bruit. C'est pourquoi Mamba abandonne la convolution fixe pour un parallel scan hardware-aware.
