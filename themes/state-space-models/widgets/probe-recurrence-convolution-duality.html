Probe d'équivalence

Une même couche, deux algorithmes : récurrence pas-à-pas ↔ convolution longue

État N=2, séquence de 6 tokens. Stepper la récurrence h_t = Ā·h_{t−1} + B̄·x_t ; en regard, le noyau K = (CB̄, CĀB̄, CĀ²B̄, …) se construit et y = K⋆x. Les sorties y_t coïncident — tant que Ā, B̄, C sont constants (LTI).

Régime
Entrée x

Mode récurrence mémoire O(N)

On ne stocke que l'état h (N=2 nombres) : chaque token coûte O(N), indépendant de la longueur déjà vue. Idéal pour l'inférence token-par-token.

Mode convolution noyau K

Le noyau K = réponse impulsionnelle (essayez l'impulsion δ : alors y_t = k_t). Précalculé une fois, y=K⋆x se parallélise sur toute la séquence (FFT en O(L log L)).

Sortie y_t : récurrence vs convolution (noyau fixe)
Pourquoi l'égalité, et pourquoi elle se brise

En déroulant la récurrence à état initial nul : h_t = Σ_{j≤t} Ā^{t−j} B̄ x_j, donc y_t = Σ_{j≤t} (C Ā^{t−j} B̄) x_j. Le poids sur x_{t−ℓ} ne dépend que du décalage ℓ : c'est k_ℓ = C Ā^ℓ B̄ — une convolution exacte. La condition est que Ā, B̄, C soient les mêmes à chaque pas (invariance temporelle, LTI).

En régime sélectif (Mamba / S6), B̄_t et C_t sont des fonctions de x_t. Le poids devient C Ā^ℓ B̄_{t−ℓ} : il dépend du contenu à la position source, plus seulement du décalage. Le noyau est temps-variant (K_t ≠ K), donc non précalculable ni applicable par FFT — d'où le balayage parallèle (parallel scan) « hardware-aware » de Mamba. Valeurs jouet, illustratives : Ā=diag(0.9, 0.4), B̄=(0.6, 0.9)ᵀ, C=(1.0, −0.5), D=0 ; gate sélective B̄_t = B̄·2σ(x_t).
