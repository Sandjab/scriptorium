Comment lire le plan ?

Chaque rectangle est un arc de faits (un EntityEdge). Ses quatre bords sont ses quatre horodatages :

  • bord gauche = valid_at, bord droit = invalid_at (axe du monde) ;
  • bord bas = created_at, bord haut = expired_at (axe du système).

Un bord pointillé signale une borne ouverte (— : toujours vrai, ou jamais périmé). Le point de requête appartient à un arc si, et seulement si, il tombe dans son rectangle. Quand le fait « CEO = Ana » est corrigé en 2024, son arc d'origine n'est pas effacé : son bord haut (expired_at) s'abaisse à 2024, et il reste interrogeable pour tout t′ antérieur — c'est l'invalidation sans effacement. Scénario simplifié à visée pédagogique.

Modèle : Zep — A Temporal Knowledge Graph Architecture for Agent Memory (arXiv:2501.13956) ; graphiti_core/edges.py (getzep/graphiti). Les champs valid_at/invalid_at sont portés par les arêtes de faits (EntityEdge), pas par chaque arête du graphe.
