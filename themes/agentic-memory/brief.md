# Brief — Agentic memory (la mémoire des agents LLM)

**Sujet (tel que fourni)** : « agentic memory ».

**Cadrage** : panorama vérifié de la *mémoire* dans les systèmes agentiques fondés sur des LLM —
comment un agent retient, structure, retrouve et oublie de l'information au-delà de la fenêtre de
contexte. Couvrir : la définition et la frontière (contexte vs mémoire externe ; mémoire vs RAG),
les types de mémoire (court terme / fenêtre de contexte, long terme, épisodique / sémantique /
procédurale), les architectures et briques (memory stream des *generative agents*, paging type
MemGPT/Letta, stores vectoriels, graphes de mémoire, opérations agentiques d'écriture/mise à
jour/consolidation/oubli comme A-MEM ou mem0), l'évaluation (benchmarks de mémoire à long terme,
métriques), les limites réelles (coût, dérive, hallucination de souvenirs, contamination,
sécurité/confidentialité) et les idées reçues. Distinguer systématiquement ce qui est **démontré**
de ce qui est **revendiqué ou prospectif**.
