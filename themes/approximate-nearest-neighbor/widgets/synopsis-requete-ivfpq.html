Requête IVF-PQ de bout en bout : IVF → résidu → table ADC → balayage → top-k → re-ranking

Un seul flux observable répond à une requête sur un index IVF-PQ jouet : 10 vecteurs de dimension 4, partagés en 3 cellules de Voronoï (quantificateur grossier IVF), chaque vecteur encodé en PQ (m = 2 sous-espaces, k* = 4 centroïdes ⇒ un code à 2 octets sur le résidu). Choisissez une requête et le nombre de cellules sondées nprobe, puis déroulez le pipeline phase par phase, ou lancez la lecture continue. Tout est calculé exactement — distances euclidiennes au carré, entières — sans aucun aléa.

Construction et requête déterministes (aucun Math.random). L'index est figé : le quantificateur grossier affecte chaque vecteur à la cellule du centroïde le plus proche, puis PQ encode le résidu r = y − c sur deux sous-espaces. À la requête, seules les nprobe cellules les plus proches sont sondées ; pour chacune, le résidu r = q − c sert à bâtir la table ADC (calcul asymétrique : la requête n'est jamais quantifiée). Balayer un code PQ revient alors à m = 2 additions d̂ = LUT[S0][a] + LUT[S1][b] — pas de décompression. Le re-ranking recalcule la distance exacte sur les vrais vecteurs des seuls candidats top-k. Augmentez nprobe pour voir le recall grimper au prix de plus de codes lus : c'est tout le compromis recall ↔ latence de l'IVF.
