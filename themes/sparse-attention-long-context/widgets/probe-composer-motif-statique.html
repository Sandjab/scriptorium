Composer un masque causal : fenêtre, dilatation, tokens globaux, tirage aléatoire, blocs

La matrice ci-dessous est le masque causal de n = 64 tokens : une case sombre est une paire (requête, clé) que le noyau calcule vraiment. Compose le motif avec les cinq réglages, lis les deux compteurs, puis pousse le curseur de profondeur : une fenêtre étroite ne borne le champ réceptif que par couche, jamais pour le modèle entier.

fenêtre locale 0 rayon dilaté 0 arêtes aléatoires 0 tokens globaux 0 hors causalité (jamais calculé) Chaque paire n'est comptée qu'une fois, attribuée au premier composant de cette liste qui la couvre — les quatre nombres se somment donc aux paires évaluées. Une paire partagée revient au composant le plus haut : retirer un composant libère au plus son compteur, jamais davantage.

n = 64 est une maquette : à w, g et r fixés le nombre de paires croît linéairement en n quand n² croît au carré, donc les fractions affichées ici surestiment largement ce que coûtent ces motifs sur des séquences de plusieurs milliers de tokens. Le compteur additionne les paires du triangle causal ; les cases au-dessus de la diagonale ne sont jamais calculées, dense ou parcimonieux. Le motif est composé à l'échelle de l'unité (un token si b = 1, un bloc de b tokens sinon), comme l'implémentation de référence de BigBird qui travaille par blocs de 64 plutôt que par positions isolées. Le rayon relatif suit la requête (une clé toutes les d unités en arrière : motif strided du Sparse Transformer, fenêtre dilatée de Longformer) ; le rayon absolu fixe les mêmes colonnes de résumé pour toutes les requêtes (motif fixed). Les deux articles combinent une tête dilatée et une tête locale, d'où la case à cocher. Ici la matrice est causale : les unités globales sont en tête de séquence, alors que l'encodeur BigBird rend aussi le dernier bloc global. Ce probe compte les paires calculées et mesure l'étendue du champ réceptif ; la distance entre deux tokens donnés est l'objet de la section suivante. Une fenêtre de w unités contient la requête elle-même : chaque couche ne recule que de w − 1 unités, d'où le + 1 des portées annoncées ci-dessus.
