Indice d'ancrage sémantique (SGI) : l'hypersphère et son angle mort

Sur le cercle unité — une coupe de l'hypersphère où vivent les embeddings normalisés — la question q, le contexte c et la réponse r. La distance géodésique entre deux points est l'angle θ = arccos(cos). Le détecteur calcule SGI = θ(r,q) / θ(r,c) : >1 = réponse tirée vers le contexte (ancrée), <1 = restée près de la question (signature d'hallucination). Glisse r sur le cercle et règle θ(q,c) : regarde l'anneau virer au gris quand q et c se rapprochent — l'angle mort.

question q contexte c réponse r (glisse-moi)

L'anneau colore chaque position possible de r par son SGI : vert = >1 (ancré), bordeaux = <1 (hallucination), gris = ≈1 (zone aveugle). Quand θ(q,c) est petit, presque tout l'anneau est gris : le SGI ne distingue plus rien.

L'invariant clé est l'inégalité triangulaire sphérique : |θ(r,q) − θ(r,c)| ≤ θ(q,c). Quand θ(q,c) → 0, les deux distances sont forcées d'être quasi égales, donc SGI → 1 pour presque toute réponse r — le détecteur est géométriquement aveugle. Mesures rapportées : AUC jusqu'à 0,83 en forte séparation angulaire, mais effondrement à 0,478 (sous le hasard, ex. TruthfulQA) quand réponses vraies et fausses sont sémantiquement proches. Le SGI mesure l'engagement thématique, pas l'exactitude factuelle.
