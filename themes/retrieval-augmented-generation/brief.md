# RAG — Retrieval-Augmented Generation

Sujet fourni : **RAG**.

Cadrage : architecture qui couple un système de **récupération d'information** (retrieval)
à un **modèle génératif** (LLM) pour ancrer les réponses sur des documents externes plutôt
que sur la seule mémoire paramétrique. Couvrir le pipeline canonique (indexation/embeddings →
récupération → augmentation du prompt → génération), les motivations (réduction des
hallucinations, fraîcheur, attribution de sources), les variantes (naïf vs avancé, re-ranking,
hybride dense/sparse, agentic/GraphRAG) et les limites/évaluations connues.
