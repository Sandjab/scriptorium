Échantillonner, exécuter, sélectionner, vérifier, réparer : la chaîne complète sur un problème jouet

Un seul énoncé, fusion(a, b) : fusionner deux listes triées d'entiers en une liste triée sans doublon. Le « modèle » est une banque de variantes tirées dans un ordre fixe ; les tests sont réellement exécutés ; rien n'est aléatoire. Chaque réglage recalcule toute la chaîne. Les chiffres qui en sortent décrivent ce jouet, pas un benchmark.
