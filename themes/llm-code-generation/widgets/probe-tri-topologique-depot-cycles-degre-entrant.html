Sonde · contexte au niveau du dépôt

Tri topologique d'un dépôt par ses imports, cycles compris

Chaque flèche se lit « A importe B ». À chaque tour, l'algorithme retire le fichier qui a le moins d'imports encore non placés (degré entrant minimal dans le graphe dépendance → utilisateur) et l'ajoute à la séquence. Quand aucun fichier n'est à zéro, il prend le minimal non nul : la dépendance en attente suivra son utilisateur dans le contexte. Cliquez un fichier puis un autre pour ajouter ou retirer un import ; cliquez une flèche pour la retirer.

Graphe d'imports ·

Le badge sur chaque fichier compte ses imports pas encore placés. Vert : zéro, le fichier est prêt. Bordeaux : minimum forcé, un import suivra.

Dans la vraie chaîne, la détection des imports se fait par expression régulière sur le mot-clé d'import du langage : elle est approximative (imports dynamiques, alias, chemins relatifs). Le dépôt ainsi concaténé est ensuite dédupliqué comme un seul échantillon. Qwen2.5-Coder marque les frontières de fichiers par le token <|file_sep|>. L'ordre obtenu est « suffisant » : il maximise les dépendances lues avant leur usage sans exiger un ordre parfait, impossible dès qu'il y a un cycle.
