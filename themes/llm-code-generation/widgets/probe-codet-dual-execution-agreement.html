Sonde · accord par double exécution (CodeT)

Candidats × tests générés : le produit |Sx|·|Sy| contre la taille du cluster seule

Le modèle a produit 10 candidats et 10 tests pour le même énoncé. Le widget exécute réellement chaque paire en JavaScript. Les candidats qui réussissent exactement le même sous-ensemble de tests forment un consensus set ; chaque règle de sélection en retient un. Cliquez un test pour le rendre toxique (attendu faux), montez le curseur pour gonfler le cluster des stubs triviaux, et regardez quelle règle se trompe.

Énoncé : plusGrandPair(xs) renvoie le plus grand élément pair de la liste, ou null s'il n'y en a aucun. (Vérité terrain connue ici : C1–C4 sont correctes, C5–C7 renvoient toujours null, C8–C10 sont fausses chacune à leur manière.)
