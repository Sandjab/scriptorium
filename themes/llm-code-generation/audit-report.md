| claim:24 | tests-oracle-best-of-n-selection | established | confirmed | 2 | 0 | 0 | 2 | soutien✓ réfutation✗~ ré-audit (session + agent, 2026-09-19)✓ | CodeT (Chen et al., Microsoft, ICLR 2023) fait générer par le modèle lui-même des cas de test, exécute chaque paire (candidat, test généré) et regroupe les candidats en « consensus sets » : les programmes qui passent exactement le même sous-ensemble S_y de tests générés forment un groupe S_x. Le score d'un consensus set, dit « dual execution agreement », n'est pas la seule taille du groupe de candidats mais le produit f(S) = \|S_x\|·\|S_y\| (nombre de solutions × nombre de tests partagés), une construction que les auteurs rapprochent du consensus RANSAC de Fischler et Bolles ; la solution retenue est tirée du consensus set de score maximal. Un travail indépendant (B4, Zhejiang University / SMU, ASE 2024) réimplémente la règle argmax \|S_x\|·\|S_y\| sur ses propres générations et cinq modèles et confirme que ce produit domine la taille du cluster seule (MBR-exec) et le nombre de tests passés (MaxPass) sur la quasi-totalité des couples modèle × benchmark, tout en montrant que CodeT se dégrade quand la proportion de solutions correctes parmi les échantillons est faible. |
