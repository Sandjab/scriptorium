Piège du classement. Comparez les deux premiers préréglages : même pass^1 (≈ 61 %), mais un pass^8 de ≈ 24 % contre ≈ 2 % selon la part de tâches solides. Le troisième agent, moins capable (pass^1 = 50 %), les dépasse tous deux en fiabilité dès k = 2. Un tableau de classement au pass^1 ne distingue rien de tout cela.

Formules exactes de τ-bench sur n essais et c succès par tâche : pass^k = Etâche[C(c,k)/C(n,k)] et pass@k = 1 − Etâche[C(n−c,k)/C(n,k)] ; le widget trace leurs formes limites E[pk] et E[1 − (1 − p)k] sur un parc à trois populations. Le profil « gpt-4o · τ-retail » est illustratif, calé sur les valeurs publiées (pass^1 ≈ 61 %, pass^8 < 25 %). Dans τ-bench, l'agent décode à température 0 : la variabilité entre essais vient surtout du simulateur d'utilisateur (température 1,0).
