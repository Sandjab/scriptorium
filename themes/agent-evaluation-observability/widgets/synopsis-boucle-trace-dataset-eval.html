La boucle trace → dataset → éval : chaque échec réel devient un cas de test

La boucle itérative documentée chez Langfuse, déroulée sur une instance jouet en 3 tours et 7 phases. Avancez phase par phase pour disséquer un tour, ou lancez la lecture continue jusqu'à convergence. Cliquez une phase du cycle pour y sauter. Tout est calculé exactement, sans aléa.

Instance jouet : un agent de support client, un seul outil disponible (chercher_commande), une politique de remboursement à 14 jours, 8 requêtes tracées par semaine. Chaque requête laisse une trace : l'arbre de ses spans (appels au modèle, appels d'outil, coût et latence par étape).

Le cycle AgentOps : la flèche ⑦ → ① (réinjection) referme le système de mesure.

Progression : l'échec en ligne baisse pendant que le jeu figé grandit.
