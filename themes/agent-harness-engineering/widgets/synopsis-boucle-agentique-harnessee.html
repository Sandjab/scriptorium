Vue d'ensemble

La boucle agentique harnessée, de bout en bout : faire passer un test qui échoue

Une instance jouet, entièrement déterministe : la suite pytest de stats.py démarre avec deux tests rouges, et un agent boucle pour la réparer. À chaque tour, huit phases s'enchaînent ; le panneau de droite montre qui porte la responsabilité. Le modèle ne fait que planifier, proposer et réfléchir ; tout le reste revient au harness : validation, autorisation, exécution, mesure, journal, arrêt. Choisissez un scénario, puis avancez pas à pas ou lancez la lecture continue jusqu'à l'arrêt. Rejouez : le film est identique, c'est la rejouabilité même.
