Sonde · convergence d'Adam

Le contre-exemple de Reddi et al. : Adam converge vers le pire point, AMSGrad non

Sur [−1, 1], la perte vaut ft(x) = C·x une étape sur trois (t mod 3 = 1) et −x les deux autres. Sur une période, la somme vaut (C − 2)·x : dès que C > 2, l'optimum est x* = −1. Les deux méthodes partent de x = 0 avec β₁ = 0 et β₂ = 1/(1 + C²), sans correction de biais, et chaque pas est projeté sur l'intervalle.

Sur une période, Adam divise le grand gradient C par √vt ≈ C : il recule d'environ α vers −1. Puis vt retombe vite, car β₂ est petit, et chacun des deux gradients −1 le repousse d'environ α vers +1. Son bilan net vaut –·α : Adam dérive vers +1, le pire point. AMSGrad garde v̂t au plafond et divise tous les gradients par ≈ C. Son bilan vaut –·α, soit environ −(1 − 2/C)·α : il rejoint −1. Avec C proche de 2, cette dérive d'AMSGrad est lente : allongez l'horizon.
