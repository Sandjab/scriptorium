# Brief — Les filtres de Bloom

Sujet fourni : « Les filtres de Bloom ».

Cadrage : structure de données probabiliste pour test d'appartenance ensembliste —
principe (k fonctions de hachage sur un tableau de bits), garanties (pas de faux négatifs,
faux positifs bornés, dimensionnement optimal), variantes (counting, scalable, cuckoo),
applications réelles et idées reçues fréquentes.
