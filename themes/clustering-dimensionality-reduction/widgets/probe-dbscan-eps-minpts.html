DBSCAN : ε et minPts re-typent chaque point en core / border / noise

Rayon de voisinage (ε) ε = 22
Seuil de densité (minPts) minPts = 4
core (≥ minPts dans ε) border (< minPts mais voisin d'un core) noise (label −1)
clusters — core — border — noise —
Survolez (ou touchez) un point : son disque ε apparaît et son type est expliqué.

Le nuage et ses 3 amas sont fixes ; seuls ε et minpts changent. Pour chaque point on compte ses voisins à distance ≤ ε : ≥ minPts ⇒ core ; sinon, voisin d'un core ⇒ border ; aucun des deux ⇒ noise. Les clusters sont les composantes connexes de core points (reliés s'ils sont à ≤ ε l'un de l'autre), chaque border s'agrégeant à un core voisin. Le calcul DBSCAN est réel et recalculé à chaque mouvement de curseur.
