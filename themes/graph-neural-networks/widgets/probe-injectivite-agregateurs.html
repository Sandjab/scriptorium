Somme, moyenne, max : qui distingue les multi-ensembles ?

Un nœud central agrège les features de ses voisins — ici trois couleurs encodées one-hot : a=(1;0;0), b=(0;1;0), c=(0;0;1). Compose deux voisinages avec les boutons −/+, choisis l'agrégateur, et observe : quand deux voisinages différents reçoivent le même message, l'agrégateur n'est pas injectif — le GNN ne pourra jamais les distinguer.

Tout est calculé en direct sur les vecteurs one-hot. Hiérarchie prouvée par Xu et al., « How Powerful are Graph Neural Networks? » (ICLR 2019) : la moyenne ne capture que la distribution des features — elle confond (S, m) et (S, k·m) (corollaire 8) ; le max ne capture que le support — il ignore toutes les multiplicités (corollaire 9) ; la somme capture le multi-ensemble complet (lemme 5, features dénombrables), d'où le choix de GIN.
