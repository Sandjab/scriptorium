Tirage bootstrap = N tirages avec remise parmi N observations. La probabilité qu'une observation donnée échappe à un tirage est (1−1/N) ; sur N tirages, (1−1/N)^N → 1/e ≈ 0,368. La grille échantillonne les multiplicités exactes du tirage ; la moyenne agrège la fraction OOB sur tous les tirages effectués.
