Capturer, représenter, désigner la cible, agir, puis recapturer pour vérifier : le cycle se répète jusqu'à ce que le modèle réponde sans outil ou que la borne de 10 itérations soit atteinte. Injectez un incident, avancez phase par phase ou lancez la lecture continue. Tout est déterministe.

Jouet pédagogique : l'écran, les coordonnées et les pannes sont inventés pour illustrer le mécanisme. La borne d'itérations, l'action d'attente et la capture de contrôle suivent la boucle décrite par la documentation du computer use tool d'Anthropic. Le script final suit le principe d'OSWorld, qui juge l'état de la machine plutôt que le récit de l'agent.
