    Journal de l'orchestrateur

    Pour situer les mécanismes : la topologie est le supervisor (orchestrator-workers) déjà posé par le harness mono-agent ; le fan-out dynamique avec un état par worker est le pattern map-reduce du Send API de LangGraph, et le checkpoint photographie l'état du graphe à chaque super-step — d'où la reprise ciblée. Le partage lecture/écriture (« les écritures restent mono-fil ») vient du débat mono vs multi-agent ; le compteur et le curseur rejouent l'argument économique : le surcoût en tokens ne se justifie que sur les tâches à large éventail dont la valeur dépasse la facture.
