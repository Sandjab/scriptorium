Frise des checkpoints

thread_id = fil-1 · checkpoint_id croissant

Reculer le curseur restaure un snapshot antérieur — sans aucune panne. Depuis ce point, relancer un super-step fourche l'historique : les anciens checkpoints sont archivés, les nouveaux continuent la numérotation.

Reprise après panne et time travel utilisent le même socle : un StateSnapshot enregistré à la fin de chaque super-step. Reprendre, c'est repartir du dernier snapshot ; voyager, c'est repartir d'un snapshot plus ancien. Comme la vague est tout ou rien (aucune écriture partielle n'est jamais visible), tout checkpoint est un point de reprise cohérent. Dans LangGraph, checkpoint_id est un identifiant croissant (UUID v6) ; ici ckpt-N croît de même, y compris après une fourche.
