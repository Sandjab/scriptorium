L'enseignant p est un mélange de deux gaussiennes ; l'élève q n'a qu'une seule gaussienne, donc il ne peut pas tout couvrir. Lecture : le forward KL Σ p·log(p/q) punit q ≈ 0 là où p > 0, donc l'élève couvre tout — quitte à mettre de la masse dans les creux, ce qui donne en génération des suites de tokens que l'enseignant juge improbables. Le reverse KL Σ q·log(q/p) punit q > 0 là où p ≈ 0 : l'élève renonce à un mode plutôt que d'inventer. La JSD généralisée interpole entre les deux via β — c'est exactement le levier étudié par MiniLLM (reverse KL), GKD (JSD généralisée) et DistiLLM pour distiller des modèles génératifs. Remarquez que β ne déforme pas l'élève continûment : il déplace un point de bascule entre les deux régimes, d'autant plus précoce que les modes de l'enseignant sont déséquilibrés.
