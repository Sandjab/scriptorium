Demi-largeur de l'IC à 95 % selon k. Sous la ligne pointillée (effet mesuré d = 0,16), l'IC exclut zéro : le résultat devient « significatif ». Empiler des sous-tests fait plonger la courbe naïve ; la courbe correcte, elle, bute sur un plancher — l'information entre participants ne se multiplie pas.

Modèle jouet : deux groupes de N participants, scores d'écart-type 1, effet mesuré fixé à d = 0,16 (un petit effet standardisé, dans l'ordre de grandeur des effets cognitifs discutés dans cette section). Erreur-type naïve : √(2/(N·k)) ; erreur-type correcte : √(2·(1+(k−1)·ρ)/(N·k)), le facteur (1+(k−1)·ρ) étant l'« effet de plan » des données en grappes. IC : intervalle de confiance, la fourchette compatible avec les données ; p : probabilité d'observer un tel écart si l'effet réel était nul (seuil usuel 0,05). C'est exactement le défaut de la réanalyse discutée ci-dessus : agrégés par participant, les intervalles s'élargissent et la significativité disparaît.
