Le masque des tokens valides, calculé au fil de la génération

À chaque position, un automate (compilé depuis la grammaire-cible) calcule l'ensemble des tokens qui maintiennent la séquence dans un JSON légal. Les tokens illégaux voient leur logit mis à −∞ : ils sont exclus du softmax quelle que soit la distribution apprise. Émets pas à pas et regarde l'ensemble admissible se restreindre puis se rouvrir selon l'état de la pile de parsing.

La grammaire-cible (GBNF jouet) 
record ::= "{" "\"nom\"" ":" string ","
           "\"tags\"" ":" array "}"
array  ::= "[" string ( "," string )* "]"
string ::= "\"Ada\"" | "\"Lin\"" | "\"ing\"" | "\"Lon\""

Soundness ≠ fidélité. La contrainte garantit que la sortie est un JSON syntaxiquement valide — jamais que ses valeurs sont vraies. La valeur de « nom » est tranchée par la distribution apprise parmi 4 chaînes légales : l'automate accepterait tout aussi bien une valeur hallucinée.
