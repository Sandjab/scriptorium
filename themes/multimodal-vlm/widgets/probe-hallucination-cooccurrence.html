Hallucination d'objets : le prior de co-occurrence contre l'image

Silhouettes bordeaux en pointillé = objets absents que le modèle « voit » ; cadre doré = objet présent mais omis de la légende.

Réellement dans l'image :
Poids du prior linguistique α = 0,20
0 — tout l'ancrage visuel1 — tout le prior

Sondage façon POPE — « Y a-t-il … dans l'image ? »

Barre = score de la réponse OUI : ancrage visuel (1−α)·v prior linguistique α·p ; trait noir = seuil de décision 0,5 ; ● présent / ○ absent dans l'image.

Légende générée
CHAIRi (hallucination)
—
objets hallucinés / mentionnés
Omissions
0
présents mais non mentionnés
Précision POPE
—
réponses correctes / 8

Modèle jouet : score(o) = α·p(o) + (1−α)·v(o), réponse OUI si score ≥ 0,5. Le prior p(o) est la co-occurrence moyenne de l'objet o avec les objets présents dans la scène (fréquences jouets imitant des données d'instruction) ; l'ancrage v vaut 0,92 si l'objet est présent, 0,08 sinon (résidu de détecteur). Le sondage oui/non reprend le protocole POPE en échantillonnage adverse — les leurres sont les objets les plus co-occurrents (Li et al., 2023) ; le compteur CHAIRi rapporte les objets hallucinés aux objets mentionnés dans la légende (Rohrbach et al., 2018). Tout est calculé exactement, sans aléa.
