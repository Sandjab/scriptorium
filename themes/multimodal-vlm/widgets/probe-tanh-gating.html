Tanh-gating : ouvrir la vision sans casser le LLM gelé

Chaque couche insérée ajoute au flux résiduel gelé une cross-attention visuelle multipliée par tanh(α), avec α initialisé à 0 : au premier pas d'entraînement, le modèle reproduit exactement le LLM texte-seul. Déplacez α pour ouvrir la porte.

y = x + tanh(0,00) · XAttn(x, V)  ⇒  y = x + 0,00 · XAttn

La porte g = tanh(α), bornée dans (−1, 1)

Contribution relative dans la somme résiduelle

Flux gelé (identité, poids 1) 100 %
Branche visuelle (poids |tanh α|) 0 %

Porte fermée (g = 0) : y = x, contribution visuelle nulle. Le modèle reproduit exactement le LLM texte-seul — c'est l'état initial de l'entraînement.

La porte s'entrouvre : la vision s'infiltre (g = 0,10) mais le flux gelé domine, la perturbation reste douce. α négatif : la contribution visuelle est soustraite.

Porte ouverte : la branche visuelle pèse 50 % de la somme résiduelle. tanh borne la porte dans (−1, 1) : la vision ne peut jamais écraser le flux gelé. α négatif : contribution soustraite (g = −0,76).

Sans gating : la cross-attention frappe à pleine puissance dès le premier pas, le LLM gelé reçoit d'emblée un signal qu'il n'a jamais vu. Ablation de l'article : −4,2 points au score global (Table 3, ligne iii).

Pourquoi cette porte ? Initialiser α à 0 garantit qu'au tout début de l'entraînement, chaque bloc restitue le LLM gelé à l'identique ; la vision ne s'infiltre que progressivement, à mesure que le gradient ouvre la porte. L'ablation de l'article Flamingo (Table 3, ligne iii) chiffre l'enjeu : sans tanh-gating, le score global chute de 4,2 points.
