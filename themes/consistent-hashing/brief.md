# Consistent hashing

Sujet : « Consistent hashing » (hachage cohérent).

Cadrage : structure de répartition de clés sur un anneau de hachage, minimisant le
remappage lors d'ajout/retrait de nœuds ; nœuds virtuels, équilibrage de charge,
applications (caches distribués, sharding, stockage clé-valeur). Run d'acceptance du
pipeline monograph (document unique + widgets pilotés par concept).
