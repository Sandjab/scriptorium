Conventions de calcul
  • Gain d'un document : 2^l − 1 ; escompte du rang r : 1/log₂(1+r) ; NDCG@10 = DCG/IDCG avec IDCG calculé sur les labels triés par pertinence décroissante.
  • Échanger deux documents ne change que leurs deux positions, d'où la forme fermée |ΔNDCG| = |2^lᵢ − 2^lⱼ| · |1/log₂(1+rᵢ) − 1/log₂(1+rⱼ)| / IDCG (les « −1 » des gains s'annulent).
  • λ RankNet pour la paire (i pertinent, j moins pertinent) : |λ| = σ/(1+e^{σ(sᵢ−sⱼ)}) avec σ = 1. Les scores sont espacés de 0,30, donc toutes les paires adjacentes ont le même λ brut.
  • MRR et MAP exigent une pertinence binaire : ici, pertinent ⇔ label ≥ 3.
  • Les flèches par document somment les λ de toutes les paires de labels distincts, signe positif pour le document le plus pertinent de la paire, négatif pour l'autre.

Lecture. La métrique de rang n'est jamais dérivée : LambdaRank multiplie le gradient pairwise de RankNet par le |Δmétrique| qu'apporterait l'échange de la paire — énorme en tête, quasi nul en queue. Remplacer NDCG par MRR ou MAP suffit à réorienter tout le champ de gradients : c'est la généricité de la recette. LambdaMART réutilise ces λ comme pseudo-gradients pour des arbres boostés.
