Un échec sur une seule base prouve que la requête est fausse ; un succès sur toutes les bases ne prouve pas l'équivalence, il la rend seulement plus probable. La suite doit donc contenir des bases capables de distinguer les requêtes : la base 3, où tout le monde suit un cours, ne départage presque rien.
