La boucle SIA, génération par génération : harness ⊥ poids, intercalés librement

Un seul Feedback-Agent répète un cycle de 5 phases sur une tâche-jouet de classification. À chaque génération il tranche librement entre deux leviers — réécrire le scaffold (harness update, poids gelés) ou entraîner les poids (weight update, scaffold gelé, LoRA rank-32, algo RL choisi selon la récompense observée). Avancez phase par phase, ou lancez la lecture continue jusqu'à convergence. Tout est calculé exactement, sans aléa.

Règle de sélection de l'algorithme RL (selon la structure de récompense observée dans τ)

Tâche-jouet déterministe (aucun aléa) inspirée de l'article SIA (Hebbar et al., 2026). L'exactitude exacte est E(h,w) = P(h) + r(h)·K(w) : le harness fixe un plafond de plomberie P qui sature à 50,0 % (= SIA-H, harness seul) ; les weight updates ajoutent une connaissance internalisée K que le scaffold ne peut atteindre, jusqu'à 70,1 % (= SIA-W+H). Le facteur r(h)=P(h)/0,5 traduit que des poids entraînés trop tôt — sur une politique faible — rapportent peu (d'où l'algo de cold-start Best-of-N). À chaque génération, Aₙ₋₁ = ℱ(Aₙ, τₙ(πθ), Eₙ, U) : le Feedback-Agent compare le gain marginal des deux leviers et choisit le plus rentable — pas de phases verrouillées. « The harness shapes how the agent searches; weight updates change what the model knows. »
