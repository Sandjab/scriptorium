la métrique qu'on optimise — monte presque toujours

—

Écart (illusion)
—
proxy − vrai : le progrès que la métrique prétend
Régime
—
—

Modèle jouet : proxy P(x)=1−e^{−3x} (monotone, saturé) ; vrai objectif T(x)=P(x)−1,25·(1−f)·x², où x est l'intensité d'optimisation et f la fidélité du proxy. Le terme (1−f)x² est le coût de sur-optimisation : nul au départ, il finit par dominer. Le point d'inversion est le pic de T : au-delà, le proxy continue de monter tandis que le vrai objectif redescend. Un proxy parfait (f=100 %) fait disparaître le pic ; baisser la fidélité le ramène vers la gauche — on peut optimiser bien moins avant que ça se retourne. C'est le piège d'un harnais qui s'optimise contre sa propre métrique.
